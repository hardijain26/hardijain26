# Hi, I'm Hardi 👋 
I'm Hardi — a Product Manager who started as a Chartered Accountant. Sounds like a weird career arc until you realize that auditing 
balance sheets and auditing user funnels are the same skill. Find where the numbers don't add up, figure out why, fix the system.
Spent the last few years at PayU building SaaS products — checkout flows, hosted payment pages, platform APIs — handling 10M+ 
transactions a day. Variance analysis on a P&L and investigating a sudden drop in checkout conversion rate? 
Same drill — isolate the variable, trace it back, find the root cause. Right now I'm between roles, building AI agents, and figuring 
out what's worth working on next.

## What I Build
AI agents that solve real problems, not wrapper demos. I pick a use case, figure out the right architecture (tools, state, orchestration), 
build a working version, and ship it. Each project is small on purpose — one agent, one job, done well. The CA also left me with one habit 
I can't shake: I build products with controls in them. If a system can fail silently, it will. So I add verification layers, catch edge cases 
before  users hit them, and don't trust outputs I can't validate. That instinct comes from audit. It turns out to be exactly what you need when 
building with AI — defining clear instructions and constraints so the model behaves the way it should, not just the way it wants to.
